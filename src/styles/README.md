# Styles Directory

This directory contains global styles and theming for the application.

## Structure

- `base/` - Reset, typography, and base styles
- `components/` - Component-specific styling
- `themes/` - Light/dark/high-contrast theme definitions
- `utils/` - Mixins, functions, variables, and helper classes

Styling follows a modular approach with clear separation between global and component-specific styles.
