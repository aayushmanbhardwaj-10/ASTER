# Components Directory

This directory contains all reusable UI components organized according to Atomic Design principles.

## Structure

- `atoms/` - Basic building blocks (buttons, inputs, labels, icons)
- `molecules/` - Groups of atoms functioning together (form fields, cards, navigation items)
- `organisms/` - Complex UI sections (headers, footers, dashboards, sidebars)
- `templates/` - Page layouts that define the overall structure of pages

Each component should be self-contained and reusable across the application.
