# Design Language
ASTER’s design language is calm, premium, and intelligent—mirroring the trustworthiness and precision required for financial decision‑making. It prioritizes clarity over ornamentation, using generous whitespace, a restrained visual hierarchy, and consistent interaction patterns to reduce cognitive load. Core elements include:
- **Brand‑Neutral Foundation:** A placeholder palette and typographic system that can be easily swapped for a client’s brand while preserving the underlying structure.
- **Unified Spatial System:** An 8‑px baseline grid that governs padding, margins, and component spacing, ensuring rhythmic alignment across all screens.
- **Elevated Elevation:** Subtle shadows and layering that convey depth without distraction, helping users understand hierarchy and focus.
- **Iconography & Illustrations:** Line‑based icons with a consistent stroke weight; illustrative sparingly used to elucidate complex concepts, always paired with clear labels.
- **States & Feedback:** Clear visual cues for loading, success, error, and disabled states, using color, motion, and micro‑interactions that are perceivable yet unobtrusive.
- **Consistency Across Modalities:** Whether viewed on desktop, tablet, or mobile, the same design tokens (spacing, typography, color, motion) apply, creating a seamless transition between form factors.
