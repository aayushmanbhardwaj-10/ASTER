# Authentication Philosophy
ASTER treats authentication as the first line of defense, ensuring that only verified identities can access the system. We adopt strong, multi‑factor authentication (MFA) as the baseline for all users, integrating standards such as FIDO2/WebAuthn, TOTP, and push‑based approvals. Password‑based authentication, when required, enforces high‑entropy passwords, password‑less recovery flows, and breached‑password checks. All authentication flows occur over mutually‑authenticated TLS, and session tokens are short‑lived, cryptographically signed, and bound to device fingerprints where possible. We centralize identity management via an OIDC‑compatible IdP (e.g., Azure AD, Okta) to enable single sign‑off, just‑in‑time provisioning, and continuous verification. Every authentication event generates an immutable audit log entry for anomaly detection and forensic analysis.
