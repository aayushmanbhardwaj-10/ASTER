# Zero Trust
ASTER operates on a Zero Trust networking model: no implicit trust is granted based on network location. Every request, whether originating from inside or outside the corporate perimeter, must be authenticated, authorized, and encrypted. Micro‑segmentation isolates workloads, and service‑to‑service communication is mutually authenticated via mTLS. Device health checks (via EDR/MDM integration) are enforced before granting access to sensitive resources. Continuous adaptive risk scoring adjusts trust levels in real time based on behavioral signals, prompting step‑up authentication or session termination when anomalies are detected. All lateral movement pathways are minimized, and visibility into east‑west traffic is provided through centralized logging and network‑flow analysis.
